📊 Data Science desde 0 — Análisis de Facturación

Repositorio donde documento mi proceso de aprendizaje en Ciencia de Datos, resolviendo desafíos reales de análisis sobre los datos de facturación de una pyme (anonimizados).

Forma parte de la serie "Data Science desde 0" que estoy publicando en LinkedIn, donde comparto el camino como estudiante de sistemas con enfoque en análisis de datos (learning in public).

🔍 Desafíos resueltos
Evolución mensual de facturación: ¿el negocio crece o se estanca?
Top 5 clientes: ¿quiénes son los que más facturan?
Concentración de clientes: ¿qué tan dependiente es el negocio de sus principales clientes?
Morosidad: análisis de días de atraso entre vencimiento y pago
Forma de pago: transferencia, efectivo o cheque, y diferencias entre clientes grandes y chicos
Estacionalidad por cliente: patrones de facturación a lo largo del año
🛠️ Herramientas

Python · Pandas · NumPy · Matplotlib · Seaborn

📌 Cómo está organizado

Cada desafío se plantea primero como problema (sin solución) y luego se resuelve paso a paso, simulando el proceso real de análisis.
